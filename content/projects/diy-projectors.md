This project started by combining halftone patterns, colors and type digitally. As I began to feel limited by the software (and/or my ability to use it), I set out to recreate these combinations manually, in analog. I eventually arrived at a fun, modular set of 3d printed projectors and DIY lenses that allow for infinite combinations of type and image.
