## Phase Goal

ROADMAP Goal (verbatim): Visitors can browse the work by feed, tag and curated homepage, read standalone pages, and open any image full-size.

User story: not authored. The ROADMAP Goal line is not in user-story format (it names no "so that" outcome), and MVP mode forbids inventing one. Run `/gsd-mvp-phase 3` to reframe it if wanted; this plan proceeds on the Goal and the five success criteria.

<objective>
Visitors can browse projects by tag: each used tag has its own page at `/tags/{slug}/`, `/work/` and the tag pages share a filter row, and every project page links to its tag pages from a Tags row.

Purpose: SITE-02 (D-08, D-09, D-10, D-11) and the "never in tag pages" half of SITE-05. Fixes the data-cascade trap that would merge the global tag list into every project once `tags.js` holds objects (RESEARCH Pattern 2, Pitfall 1), and decouples the test suite from the owner's placeholder tag list.
Output: `{ slug, label }` tags, tag pages, `filters.njk`, the Tags row, `validateTagDefs`, fixture tags in the test helper, updated tests.
</objective>
