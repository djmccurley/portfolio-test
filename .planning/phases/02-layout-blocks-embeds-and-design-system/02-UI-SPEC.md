# Phase 02 — UI Design Contract

> Visual and interaction contract for Phase 02: Layout Blocks, Embeds and Design System. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> This is a static, zero-framework Eleventy site. The "design system" is one hand-written `content/style.css` driven by CSS custom properties. There is no component library, no Tailwind and no `components.json`. Values below are binding defaults the owner will later tune in one place (the `:root` token block).

Sources: decisions D-01..D-15 from `02-CONTEXT.md` (locked); Phase 1 code (`src/_includes/base.njk`, `content/style.css`, `lib/images.js`, `lib/markdown.js`); items marked "(default)" are researcher recommendations within Claude's Discretion.

## Layout Contract

### Page column (D-12)

One wide column, left-aligned, generous side margins. No centred text, no centred headings, no narrow centred reading column.

| Token | Value | Usage |
|-------|-------|-------|
| `--page-margin` | `clamp(1rem, 5vw, 4rem)` (16px at phone, 64px at wide) | Side margin on both sides of the column |
| `--column-max` | `80rem` (1280px) | Max width of the wide column |
| `--measure` | `40rem` (640px, about 65 characters at body size) | Max width of prose only (paragraphs, headings, lists, `<dl>`, blockquote) |

Implementation pattern (named-line grid, no `100vw` hack, no horizontal scrollbar):

```css
main {
  display: grid;
  grid-template-columns:
    [full-start] minmax(var(--page-margin), 1fr)
    [content-start] min(100% - 2 * var(--page-margin), var(--column-max))
    [content-end] minmax(var(--page-margin), 1fr)
    [full-end];
}
main > * { grid-column: content; }
main > .full { grid-column: full; }
```

Rules:
- Every direct child of `<main>` sits in the `content` column and starts at its left edge. Prose children (`p, h1-h3, ul, ol, dl, blockquote, pre`) additionally get `max-width: var(--measure)` and stay left-aligned (never `margin-inline: auto`).
- Header and the site `<header>` use the same page margin and left alignment (put the header inside the same column grid or give it `padding-inline: var(--page-margin)` and `max-width` matching the column).
- Grids, lone images, video and itch embeds use the full `content` column width (D-12). Note: D-05 and D-09 say "text column"; this contract reads that as "the one wide column", with only prose capped at `--measure`.
- `.full` blocks span `full-start` to `full-end` (true edge-to-edge, D-03).
- `.full` captions are inset so text never touches the viewport edge: `figcaption` inside `.full` gets `padding-inline-start: max(var(--page-margin), calc((100% - var(--column-max)) / 2))` and `padding-inline-end: var(--page-margin)`.
- No sidebar, no sticky elements, no multi-column page chrome.

### Block rendering contract

All blocks are flat (no nesting, D-05). Output markup is fixed so CSS and tests can rely on it.

| Block (fence) | Output markup | Layout |
|---------------|---------------|--------|
| `::: grid-2` | `<div class="layout grid-2">` with one `<figure>` per image | 2 columns |
| `::: grid-3` | `<div class="layout grid-3">` with one `<figure>` per image | 3 columns |
| `::: grid-4` | `<div class="layout grid-4">` with one `<figure>` per image | 4 columns |
| `::: full` | `<div class="layout full">` with one `<figure>` per image, stacked vertically | edge to edge |
| `::: video <url> "Title"` | `<div class="embed">` wrapping iframe (YouTube/Vimeo) or `<video>` (self-hosted) | wide column |
| `::: itch <embed> WxH "Title" <page>` | `<div class="embed itch">` wrapping iframe, followed by the "Play on itch.io" link | wide column, capped at W px |
| `::: video full ...`, `::: itch full ...` | same as above plus class `full` | edge to edge (D-09) |
| lone `![alt](p "Cap")` | `<figure><img><figcaption>` in the column | wide column |
| lone `![alt](p)` | `<p><img></p>` in the column | wide column |
| raw HTML | passes through untouched (AUTH-04) | whatever the HTML does; sits in the column grid like any other child |

Rules:
- Inside `grid-N` and `full`, markdown puts consecutive `![](...)` lines in one `<p>`; the renderer unwraps them so each image is its own `<figure>` (a `<figure>` with no `<figcaption>` when there is no title).
- Caption (D-02): `![alt](path "Caption")` becomes `<figure><img alt="alt"><figcaption>Caption</figcaption></figure>`. Alt and caption are separate; never copy one into the other.
- Reading order in the DOM is across-then-down (no masonry, no CSS `columns`, D-14).
- Empty block (a grid or full block with zero images) fails the build (see Copywriting Contract).

### Grid behaviour (BLOCK-05, BLOCK-06, D-14)

```css
.layout { display: grid; gap: var(--grid-gap); align-items: start; }   /* top-aligned rows */
.layout img { display: block; width: 100%; height: auto; }              /* own aspect ratio, never cropped */
.grid-2 { grid-template-columns: repeat(2, minmax(0, 1fr)); }
.grid-3 { grid-template-columns: repeat(3, minmax(0, 1fr)); }
.grid-4 { grid-template-columns: repeat(4, minmax(0, 1fr)); }
```

Collapse breakpoints (pure CSS, media queries in `em`, no JS; custom properties cannot be used inside `@media`, so these are literals):

| Block | `>= 60em` (960px) | `40em - 59.99em` (640-959px) | `< 40em` (under 640px) |
|-------|-------------------|------------------------------|------------------------|
| grid-2 | 2 columns | 2 columns | 1 column |
| grid-3 | 3 columns | 2 columns | 1 column |
| grid-4 | 4 columns | 2 columns | 1 column |

- Forbidden in grids: `object-fit: cover`, fixed heights, `aspect-ratio` forcing on images, `overflow: hidden` on cells. Images keep their own ratio (width/height attributes from eleventy-img prevent layout shift).
- Shorter images leave empty space below them; each caption sits directly under its own image.
- A grid with fewer images than columns (for example 1 image in `grid-3`) occupies the first cell and leaves the rest empty. This is accepted behaviour, not an error.
- Embeds and lone images are not grids and are never affected by the collapse table.

### Image `sizes` per block (replaces the global value in `lib/images.js`)

Column width `W = min(90vw, 1280px)`; grid gap 16px. Widths from Phase 1 stay `[480, 960, 1600, 2400]`.

| Context | `sizes` |
|---------|---------|
| lone image / default | `(min-width: 90em) 1280px, 90vw` |
| `full` | `100vw` |
| `grid-2` | `(min-width: 90em) 632px, (min-width: 40em) 45vw, 90vw` |
| `grid-3` | `(min-width: 90em) 416px, (min-width: 60em) 30vw, (min-width: 40em) 45vw, 90vw` |
| `grid-4` | `(min-width: 90em) 308px, (min-width: 60em) 22vw, (min-width: 40em) 45vw, 90vw` |

The global `sizes` default becomes the lone-image value (the old `(min-width: 60em) 60em, 100vw` no longer matches the layout). The first image on a page stays `loading="eager"` + `fetchpriority="high"` (Phase 1); this applies even when it is inside a block.

### Embed behaviour

| Embed | Sizing | Required attributes |
|-------|--------|---------------------|
| YouTube / Vimeo (D-06) | `width: 100%` of column (or full-bleed with `full`), `aspect-ratio: 16 / 9`, `border: 0` | `title="<quoted title>"`, `loading="lazy"`, `allow="fullscreen; picture-in-picture"`, `allowfullscreen`, `referrerpolicy="strict-origin-when-cross-origin"`; src on `www.youtube-nocookie.com/embed/<id>` or `player.vimeo.com/video/<id>?dnt=1` |
| Self-hosted (D-07) | `<video controls preload="metadata">`, `width: 100%`, `height: auto`, black background | no `autoplay`, no `loop` unless the owner writes raw HTML; optional `poster`; src ends `#t=0.001` so iOS Safari paints a first frame when no poster is given (default; planner to verify on iOS); `aria-label="<title>"`; fallback content below |
| itch.io (D-08) | `aspect-ratio: W / H`, `width: 100%`, `max-width: Wpx` (native game width, left aligned); with `full` the max-width cap is removed | `title="<quoted title>"`, `loading="lazy"`, `allow="fullscreen"`, `allowfullscreen`, `border: 0` |

- The quoted title is the accessible name only. It is not rendered as visible text (consistent across all three embeds). Visible text under an embed exists only for the itch link.
- Self-hosted video fallback content (shown when `<video>` is unsupported): `<p>Your browser cannot play this video. <a href="{src}">Download "{title}"</a></p>`.
- `.embed` iframes and videos need the same focus ring as links (`:focus-visible`).
- itch link sits directly under the iframe: `<p class="embed-link"><a href="{page-url}">Play on itch.io<span class="visually-hidden">: {title}</span></a></p>`. Text is body size, underlined like any link.
- Embeds are always rendered; there is no click-to-load facade in v1 (POL-03 deferred).

## Spacing Scale

Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px (0.25rem) | Underline offset, inline gaps |
| sm | 8px (0.5rem) | Caption gap under an image, `<dt>`/`<dd>` gaps |
| md | 16px (1rem) | `--grid-gap` (D-13); paragraph-to-paragraph spacing; skip-link padding |
| lg | 24px (1.5rem) | Spacing under h1/meta block |
| xl | 32px (2rem) | `--block-gap` (D-13): any gap that touches a block (paragraph to grid, grid to full, full to text, embed to anything) |
| 2xl | 48px (3rem) | Space above h2 / h3 |
| 3xl | 64px (4rem) | Maximum `--page-margin` (wide screens), space above footer area |

Tokens in CSS:

```css
:root {
  --grid-gap: 1rem;
  --block-gap: 2rem;   /* 2 x --grid-gap, D-13 */
}
```

Vertical rhythm is set with margin-top only, using a lobotomised owl on `main`'s children (avoids margin-collapse differences inside a CSS grid):

| Between | Gap |
|---------|-----|
| prose element and prose element (p, ul, ol, blockquote) | 16px (`--grid-gap`) |
| anything and a block (`.layout`, `.embed`, `figure`, lone `<p><img>`), either side | 32px (`--block-gap`) |
| anything and h2 / h3 | 48px above, 16px below |
| images / cells inside a grid or full block | 16px (`--grid-gap`) |
| image and its caption | 8px |

Exceptions:
- `--page-margin` is fluid (`clamp(1rem, 5vw, 4rem)`), not a fixed step. Its endpoints (16px, 64px) are on the scale.
- Skip link padding is 12px 16px to give a target of at least 44px tall at body size (12 is a multiple of 4).
- Intrinsic image and embed dimensions come from the content, not the scale.

## Typography

Font: Chivo. Declared sizes: exactly 4. Declared weights: exactly 2 (400 regular, 700 bold). Italic is a style (400 italic), not a third weight. All sizes in `rem` so browser text-size settings work.

| Role | Size | Weight | Line Height | Used for |
|------|------|--------|-------------|----------|
| Body | 18px (1.125rem) | 400 | 1.5 | Paragraphs, lists, links, `<dd>`, itch link, header site-name (700) |
| Label | 14px (0.875rem) | 400 (italic for captions) | 1.5 | `figcaption` (italic), `<dt>` (700), `<time>` / meta line |
| Heading | 24px (1.5rem) | 700 | 1.2 | `<h2>`; `<h3>` uses Body size at 700 |
| Display | 40px (2.5rem) | 700 | 1.2 | Page `<h1>` (project title) |

Rules:
- Headings are left-aligned, never centred, no letter-spacing, no uppercase transform, no text-shadow.
- `<h1>` uses `font-size: clamp(1.75rem, 6vw, 2.5rem)` only if needed on phones; otherwise fixed 2.5rem. Keep wrap with `overflow-wrap: break-word` on headings and captions so long words never cause horizontal scroll.
- `<dt>` in the project meta block: 14px, 700. `<dd>`: 18px, 400. Present them as a two-column grid at `>= 40em` (`dt` column auto, `dd` column 1fr) and stacked below that. No box, no border, no background.
- Links: colour `--accent`, always underlined (`text-decoration: underline; text-decoration-thickness: 0.08em; text-underline-offset: 0.2em`). Visited links keep the same colour (single accent, D-11). Hover/focus changes nothing except the focus ring (no transitions, D-15).
- Strong = 700, emphasis = 400 italic. No other weights are used anywhere (the variable font is loaded for flexibility but the stylesheet uses only 400 and 700).
- `<hr>` and `<blockquote>`: 2px solid `--ink` rule / left border, no decoration.
- `<code>`, `<pre>`: `ui-monospace, monospace` at 14px; `pre` wraps with `white-space: pre-wrap` (never horizontally scrolls the page).

## Color

Black text on white plus one accent (D-11). The 60/30/10 split is interpreted for a monochrome site.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFFFFF` (`--paper`) | Page background |
| Secondary (30%) | `#000000` (`--ink`) | All text, rules, blockquote border, video letterbox background, skip-link background |
| Accent (10%) | `#0000EE` (`--accent`, placeholder, 8.6:1 on white, AA and AAA pass) | See reserved list |
| Destructive | none | No destructive actions exist in this phase |

Accent reserved for:
1. Inline links and the itch "Play on itch.io" link (text and underline).
2. The `:focus-visible` outline on every focusable element.
3. The skip link's focus outline.

Accent is not used for: headings, backgrounds, borders, captions, buttons, hover effects.

Custom properties (the one place the owner edits colour):

```css
:root {
  --paper: #fff;
  --ink: #000;
  --accent: #0000ee;  /* placeholder, must stay >= 4.5:1 on --paper (A11Y-03) */
}
```

Contrast contract (A11Y-03):
- `--ink` on `--paper`: 21:1.
- `--accent` on `--paper`: must be >= 4.5:1 for text; focus outline must be >= 3:1 against its neighbours. The planner adds a build or test check that computes this ratio from the token so the owner cannot silently break it when changing the hex.
- Captions and labels are `--ink`, differentiated by size and italic, not by a grey. No grey text anywhere (avoids AA failures at 14px).
- No dark mode this phase (POL-01 is v2). Set `color-scheme: light` on `:root` so UA widgets stay consistent.

## Interaction & Accessibility Contract

| Concern | Contract |
|---------|----------|
| Motion (A11Y-01) | No `transition`, `animation`, `scroll-behavior: smooth` or transforms-on-hover anywhere. Add a guard anyway: `@media (prefers-reduced-motion: reduce) { *, *::before, *::after { animation: none !important; transition: none !important; scroll-behavior: auto !important; } }`. |
| Skip link (A11Y-03) | First focusable element in `<body>`: `<a class="skip-link" href="#main">Skip to main content</a>`. Target is `<main id="main" tabindex="-1">`. Hidden off-screen until focused; on focus it appears at top-left (`position: absolute; top: 0; left: 0`), black background, white text, 12px 16px padding, 18px 700, with the accent outline. It never uses `display: none` or `visibility: hidden` (would remove it from the tab order). |
| Focus (A11Y-03) | `:focus-visible { outline: 3px solid var(--accent); outline-offset: 3px; }` on `a, video, iframe, summary, button, [tabindex]`. Never `outline: none` without a replacement. `main:focus { outline: none; }` is allowed only for the programmatic `tabindex="-1"` skip target. |
| Landmarks | `<header>` with the site-name link, `<main id="main">`. Exactly one `<h1>` per page (the title). Headings in markdown content start at `##`; do not skip levels. |
| Language | `<html lang="en">` already present; keep it. |
| Images | Every `<img>` has an `alt` attribute. Decorative images carry `alt=""` (see marker below). Alt-text lint warnings per Copywriting Contract. |
| Embeds | Every iframe has a non-empty `title`. Every `<video>` has `aria-label`. Games get a visible alternative link. Pointer-only interaction is not required anywhere. |
| Zoom / reflow | All sizes in `rem`/`em`/`%`/`fr`; `min-width: 0` on grid children; `overflow-wrap: break-word` on prose, captions and links. Formal 320px / 200% verification is Phase 4 (A11Y-02), but this phase must not introduce fixed pixel widths on containers. |
| Print / other | Not in scope. |

Decorative image marker (A11Y-04, default): `![](../../assets/rule.webp){decorative}` via markdown-it-attrs. The renderer sets `alt=""`, removes the `decorative` attribute from the output, and the lint skips it. A decorative image may still have a title/caption.

## Copywriting Contract

This is a content site, not an app. Rows are the strings that Phase 2 adds to the shipped output and to the build console. Visitor-visible strings are exact; build messages follow the Phase 1 `${page.inputPath}: ...` style (D-23) and must name the file and the block/image.

### Visitor-facing

| Element | Copy |
|---------|------|
| Skip link | `Skip to main content` |
| Site name link (header) | `Portfolio` (existing; owner may change it later) |
| itch fallback link | `Play on itch.io` (visually-hidden suffix `: {Title}` for screen readers) |
| Self-hosted video fallback | `Your browser cannot play this video. Download "{title}"` (link text is `Download "{title}"`) |
| Primary CTA | `Play on itch.io` (the only call to action in this phase) |
| Empty state | not applicable: blocks with no content fail the build rather than rendering empty |
| Destructive confirmation | not applicable: no destructive actions |

### Build errors (fail the build, D-04 / D-06 / D-07 / D-08)

| Condition | Message |
|-----------|---------|
| Unknown fence name | `{file}:{line}: unknown block "::: {name}". Valid blocks: grid-2, grid-3, grid-4, full, video, itch.` |
| Unclosed fence | `{file}:{line}: block "::: {name}" is never closed. Add ":::" on its own line after the content.` |
| Non-image content in grid/full | `{file}:{line}: block "::: {name}" may only contain images. Move the text outside the block or use raw HTML.` |
| Empty grid/full | `{file}:{line}: block "::: {name}" has no images.` |
| Video missing title | `{file}:{line}: video block needs a quoted title: ::: video <url> "Title"` |
| Video URL not recognised | `{file}:{line}: video URL not recognised: {url}. Use a youtube.com, youtu.be or vimeo.com link, or a file in assets/.` |
| Self-hosted video missing | `{file}:{line}: video not found in assets/: {path}` |
| Self-hosted video too large | `{file}:{line}: video {name} is {N} MB; the limit is {cap} MB.` (default cap 50 MB, planner confirms; GitHub Pages limit is 100 MB per file) |
| itch missing/invalid args | `{file}:{line}: itch block needs: ::: itch <embed-url> <W>x<H> "Title" <itch-page-url>` |

### Build warnings (do not fail; A11Y-04, default)

Printed to the console once per image, never silently dropped:

| Condition | Message |
|-----------|---------|
| Empty alt, not marked decorative | `WARN {file}: image {path} has empty alt text. Describe it, or add {decorative} if it is purely visual.` |
| Paste placeholder alt `alt text` | `WARN {file}: image {path} still has the paste placeholder alt "alt text". Replace it with a description.` |
| Filename-like alt (`IMG_1234`, `screenshot-2026-...`, ends in an image extension, or equals the file basename) | `WARN {file}: image {path} has alt text that looks like a filename ("{alt}"). Describe what the image shows.` |

Alt-text guidance for the future README (Phase 4) is out of scope here.

## UI Considerations

Applicable state considerations resolved: 10 covered, 3 backstop, 2 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | grid / full block with zero images (list-collection) | ✅ covered | A grid or full block with no images fails the build with the "has no images" message; no empty `<div>` is ever published |
| zero-one-many | grid-N with 1..N images (list-collection) | ✅ covered | One image in `grid-3` fills the first cell and leaves the others empty; two in `grid-3` fill cells 1 and 2; no stretching or re-centring |
| overflow | grid-N with more images than columns (list-collection) | ✅ covered | Images wrap to a new row (across-then-down), top-aligned, 16px gap; no scrolling or truncation |
| populated | `::: full` with several images (media) | ✅ covered | Images stack vertically edge to edge with a 16px gap; each caption is inset to the column's left edge |
| long-text | figcaption in a narrow grid cell (static-content) | ✅ covered | Captions wrap with `overflow-wrap: break-word`; never truncated or ellipsised; the row grows and neighbouring cells stay top-aligned |
| long-text | video / itch title, itch link text (interactive-control) | ✅ covered | Titles are accessible names only (not rendered) except the visually-hidden itch suffix; the itch link wraps normally |
| error | embed whose iframe cannot load (media) | ✅ covered | The itch block always shows the "Play on itch.io" link beneath the frame; the YouTube/Vimeo title attribute stays; no JS fallback needed |
| error | video file unsupported (media) | ✅ covered | `<video>` fallback paragraph with a download link |
| error | image file missing / bad block syntax | ✅ covered | Build fails naming the file (Phase 1 D-23 / D-04); never published broken |
| partial | project meta `<dl>` with only some fields (static-content) | ✅ covered | Existing `base.njk` conditionals omit absent `<dt>/<dd>` pairs; the grid layout of the `<dl>` collapses cleanly to fewer rows |
| loading | images (media) | 🧪 backstop | `width`/`height` attributes from eleventy-img reserve space (no layout shift); lazy loading for all but the first image; verified visually on a throttled page load |
| loading | embeds before they load (media) | 🧪 backstop | Reserved space comes from `aspect-ratio`; no spinner or placeholder text; verify no layout shift when iframes load |
| empty | self-hosted video with no `poster=` (media) | 🧪 backstop | Falls back to `preload="metadata"` + `#t=0.001`; first-frame rendering on iOS Safari needs a manual device check |
| overflow | very wide raw-HTML tables / pre (static-content) | ⚠ unresolved | Raw HTML is the owner's responsibility (AUTH-04); only `pre` is wrapped by default. Planner treats other raw HTML overflow as an assumption; formal check is Phase 4 (A11Y-02) |
| long-text | very long project title in `<h1>` (static-content) | ⚠ unresolved | `overflow-wrap: break-word` is specified, but the exact `h1` size at 320px is verified in Phase 4 |
