## Phase Goal

**As a** portfolio owner, **I want to** write a project markdown file with a pasted image and push it to GitHub, **so that** I see it live on a deployed site with optimized images.

<objective>
This plan covers edge cases for the image slice. When the owner pastes a transparent screenshot, an animated GIF or an SVG, the visitor sees it correctly: the alpha channel survives, the GIF still animates and the SVG stays a vector. Every case keeps width/height and the eager-first rule.

Purpose: AUTH-03 says GIFs and transparency must be "handled safely". RESEARCH Pitfalls 4 and 9 say the default config gets both wrong.
Output: alpha detection in lib/assets.js, per-image format selection in lib/markdown.js, GIF animation in lib/images.js, and tests.
</objective>
