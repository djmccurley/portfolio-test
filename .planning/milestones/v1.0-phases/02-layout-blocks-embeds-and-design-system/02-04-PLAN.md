## Phase Goal

**As a** portfolio owner, **I want to** compose a rich project page by typing short block shorthand that mixes grids, full-width images, text, video and playable games, **so that** it renders as an accessible brutalist page.

<objective>
This plan lets the owner paste a YouTube or Vimeo link, or an itch.io game, into a short `:::` block and have visitors watch or play it in a titled, lazy-loaded, privacy-friendly iframe, with a visible "Play on itch.io" link under every game.

Purpose: MEDIA-02 and MEDIA-03 (D-06, D-08, D-09). The handlers plug into the `EMBEDS` Map that plan 02-01 created; the frame CSS (16:9, itch W/H ratio, full bleed) is in plan 02-02. Self-hosted video (the file branch of `::: video`) is plan 02-05.
Output: lib/embeds.js, two Map registrations plus a no-content check in lib/blocks.js, test/embeds.test.js.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Owner-authored fence args -> generated iframe HTML | URLs and titles from markdown become attribute values |
| Visitor browser -> third-party players (YouTube, Vimeo, itch.io) | Iframes load cross-origin content |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-09 | Spoofing | videoEmbedSrc host matching (`youtube.com.evil.com`, `javascript:`) | high | mitigate | `new URL()` + exact-hostname Sets + protocol check; src rebuilt from a regex-validated ID; tests assert hostile inputs return null |
| T-02-10 | Tampering | Attribute injection via title or URL in the fence line | high | mitigate | Every attribute value and text node goes through escapeAttr (`& < > "`); the quote-aware parser ends a title at the first `"`; tests assert escaped output |
| T-02-11 | Elevation of privilege | itch iframe runs third-party scripts | medium | mitigate | Only https URLs on itch.io / *.itch.io / *.itch.zone are accepted; `allow` limited to fullscreen; content is cross-origin so the browser isolates it from the page; no sandbox because games need scripts (research Security Domain) |
| T-02-12 | Information disclosure | Tracking cookies and referrer data sent to video providers | medium | mitigate | YouTube via www.youtube-nocookie.com, Vimeo with dnt=1, `referrerpolicy="strict-origin-when-cross-origin"` (origin only, never the full page URL) |
| T-02-SC | Tampering | npm/pip/cargo installs | high | accept | This plan installs no packages; it uses the lockfile from plan 02-01 via `npm ci` in CI |
</threat_model>
