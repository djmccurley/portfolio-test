## Phase Goal

**As a** portfolio owner, **I want to** compose a rich project page by typing short block shorthand that mixes grids, full-width images, text, video and playable games, **so that** it renders as an accessible brutalist page.

<objective>
This plan makes the build tell the owner when an image's alt text is missing, still the VS Code paste default, or looks like a filename, with a deliberate `{decorative}` escape hatch (A11Y-04). It also turns the sample tidepool page into a live demo of the new blocks with real alt text, so the repo builds clean.

Purpose: A11Y-04 is Claude's discretion in CONTEXT.md: warn rather than fail, name the file and image path, and use a quick decorative marker. The marker syntax and its `alt=""` output were built in plan 02-01; this plan adds the lint that reads it.
Output: lib/alt-lint.js, lint wiring in lib/markdown.js, a per-build reset in eleventy.config.js, test/alt-lint.test.js, and an updated content/projects/tidepool-game.md.
</objective>
