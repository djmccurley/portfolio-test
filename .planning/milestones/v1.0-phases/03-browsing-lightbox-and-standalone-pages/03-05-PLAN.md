## Phase Goal

ROADMAP Goal (verbatim): Visitors can browse the work by feed, tag and curated homepage, read standalone pages, and open any image full-size.

User story: not authored. The ROADMAP Goal line is not in user-story format (it names no "so that" outcome), and MVP mode forbids inventing one. Run `/gsd-mvp-phase 3` to reframe it if wanted; this plan proceeds on the Goal and the five success criteria.

<objective>
Visitors can open any content image full-size: a plain link to the largest published variant that works without JavaScript, enhanced by one small first-party script into a native `<dialog>` viewer that is keyboard-operable, closes on Escape, Close or a surface click, and returns focus to the image.

Purpose: IMG-05 (D-01, D-02, D-03, D-04) and ROADMAP success criterion 5.
Output: `lib/zoom.js`, the zoom wrapper in `lib/blocks.js`, the transform registration, `content/lightbox.js`, the script gate in `base.njk`, dialog CSS, and zoom, lightbox, design and contrast tests.
</objective>
